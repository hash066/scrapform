# Three-minute demo

1. Point out `AWS Amplify OSS · saved` and the Solve Ledger. Edit one measured width, watch the lifecycle advance, reload, and show that the complete workspace recovers.
2. Show measured offcuts and defect zones. Select a product, set batch quantity to two, and change its width; point out the live 3D assembly and recalculated cut plan.
3. Remove the largest stock piece. Show the explicit infeasible state, failed ledger record, and disabled exports.
4. Restore/add stock and show the independent validation result.
5. Use the working 3D/Layout segmented control. Edit price, maker cost, shipping and marketplace fee; download the verified maker offer and fabrication exports.
6. Finish on the public URL and AWS architecture. State that the public build uses the AWS-maintained Amplify OSS runtime locally, cloud resources are not claimed as deployed, commercial values are assumptions, and geometry is computed and validated.
