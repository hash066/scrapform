# Three-minute demo

1. Show measured offcuts and the defect zones. Change an offcut dimension.
2. Select a product, set batch quantity to two, and change its width; point out the live 3D assembly and recalculated cut plan.
3. Remove the largest stock piece. Show the explicit infeasible state and disabled exports.
4. Restore/add stock and show the independent validation result.
5. Use the working 3D/Layout segmented control. Edit price, maker cost, shipping and marketplace fee; download the verified maker offer and fabrication exports.
6. Finish on the AWS architecture and the public URL. State that price and impact fields are assumptions, while geometry is computed and validated.
